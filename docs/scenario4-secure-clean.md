# 场景四方案:数据残留安全清理(SecureClean)

## 定位

从"清理垃圾"升级为"**安全清理**"——不只是删文件,而是**检测并彻底清除磁盘上的敏感数据残留**,防止数据泄露。这是杀毒软件和系统清理**都不做**的差异化方向,且契合你的 IntrusionScope 取证背景。

**一句话**:别人做"清理",你做"安全清理"——检测"你以为删了其实还在"的数据,并彻底清除。

---

## 一、目标用户与痛点

| 目标用户 | 痛点 | 付费意愿 |
|---------|------|---------|
| **注重隐私的个人** | 换电脑/卖电脑前,担心聊天记录、登录凭证、文件残留泄露 | 中高 |
| **企业员工/离职交接** | 离职前需清除工作电脑上的敏感数据 | 高(企业付费) |
| **二手设备卖家** | 卖二手手机/电脑前,需彻底清除个人数据 | 中高 |
| **安全敏感人群**(记者/律师/医生) | 处理敏感信息,需确保数据不可恢复 | 高 |
| **数据泄露受害者** | 担心已泄露数据,需排查残留 | 中 |

## 二、核心功能(分阶段)

### 阶段 1:敏感数据残留扫描(检测)
- **扫描范围**:临时文件、浏览器缓存/登录态、聊天记录缓存(微信/QQ)、登录凭证、回收站、系统日志
- **检测能力**(复用 IntrusionScope 取证技术):
  - 识别"看似删除、实际可恢复"的数据残留
  - 识别敏感文件类型(凭证、聊天记录、浏览器数据)
  - 生成**残留报告**:哪些地方残留了敏感数据、风险等级
- **输出**:可视化报告(哪些可安全删、哪些需彻底清除)

### 阶段 2:安全清除(删除)
- **彻底删除**:覆盖写入(overwrite)或安全擦除,确保数据不可恢复
- **分类清除**:
  - 可安全删:临时文件、缓存
  - 需彻底清:登录凭证、聊天记录、敏感文件
- **清除报告**:清除后出具"已安全清除"证明

### 阶段 3:合规报告(变现)
- 清除完成后生成**合规报告**:扫描了什么、清除了什么、残留风险等级
- 面向企业:作为数据合规/离职交接的凭证

## 三、技术实现

### 复用 IntrusionScope 的能力
- **取证检测引擎**:IntrusionScope 已有 37 个采集器 + Rust 检测引擎,可复用其"检测残留/敏感数据"的能力
- **IFQL 查询**:可用来精确定位敏感数据位置
- **多格式报告**:JSON/CSV/HTML,可直接用于残留报告

### 新增能力
- **安全擦除**:覆盖写入算法(如 DoD 5220.22-M 标准)或文件粉碎
- **残留检测规则**:针对"聊天记录缓存、登录凭证、浏览器数据"的专项规则
- **清除引擎**:分类清除 + 报告生成

### 技术栈建议
- 核心引擎:复用 IntrusionScope 的 Go/Rust(高性能、跨平台)
- 或轻量版:PowerShell 脚本(快速原型,验证需求)

## 六、风险与合规

### 风险
- **误删风险**:清除前需确认,避免删到在用数据
- **合规风险**:安全清除涉及数据销毁,需符合法规(如 GDPR、个人信息保护法)
- **信任风险**:用户担心工具本身是否安全(需开源/透明)

### 合规要点
- **不教攻击**:内容侧重"防御/清理",不教如何获取他人数据
- **明确授权**:只清理用户自己的设备,不涉及他人数据
- **透明**:工具开源或可审计,建立信任

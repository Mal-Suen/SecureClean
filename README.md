# SecureClean

敏感数据残留检测与隐私泄露面体检工具。检测"你以为删了其实还在"的数据,
以及软件搬家/卸载后留下的孤儿数据——这两类都是杀毒软件清理不覆盖的场景。

## 功能

### 隐私体检(换机/卖机场景)
扫描这台电脑会泄露哪些隐私:
- 浏览器:保存的密码、登录态 Cookie、浏览历史、自动填充、本地存储
- 聊天记录:微信/QQ/企业微信数据
- 登录凭证:Windows 凭据管理器、SSH 私钥、Git 明文凭证
- 可恢复数据:回收站(普通删除可被还原)、最近使用记录

### 残留检测(搬家/卸载场景)
检测杀毒软件不识别的孤儿数据:
- 孤儿目录:Program Files 下无注册表/PATH/进程引用的目录(四层豁免防误报)
- 悬空注册表:卸载项指向已不存在的位置
- PATH 失效引用:环境变量指向不存在的目录

### 安全清除
- 目录/文件:覆盖写入随机数据后删除,防止数据恢复
- 注册表项:删除悬空的卸载注册表项
- PATH 条目:从用户级环境变量移除失效条目
- 凭据:删除凭据管理器保存的登录凭据

### 风险报告
汇总隐私体检与残留检测结果,输出 0-100 风险评分与分级建议。

## 技术栈

Electron(主进程 Node.js + 渲染进程 HTML/CSS)。UI 遵循 Apple 设计语言
(见 DESIGN.md):浅色羊皮纸背景、单一 Action Blue 强调色、8px 圆角。

## 运行

```
cd app
npm install --registry=https://registry.npmmirror.com
npm start
```

## 目录结构

```
SecureClean/
├── app/               # Electron 应用(当前版本)
│   ├── main.js        # 主进程: 扫描/清除逻辑 + IPC
│   ├── preload.js     # contextBridge
│   ├── index.html     # 渲染进程: Tab UI + 折叠分组表格
│   └── package.json
├── docs/              # 产品方案文档

```

## 与杀毒软件清理的区别

| 维度 | SecureClean | 杀毒软件清理 |
|------|-------------|-------------|
| 搬家/卸载残留 | 专门检测(注册表/PATH/进程交叉验证) | 不识别 |
| 隐私泄露面 | 按换机场景输出风险报告 | 不做 |
| 删除方式 | 覆盖写入,防数据恢复 | 普通删除,可被恢复 |
| 常驻后台 | 无,用完即走 | 有 |
